# Microservicio de Autenticación

Clonar el repositorio

```
git clone tu_repo
cd tu repo
```

Levantar la base de datos
```
docker compose up -d
```

Ejecutar el archivo de siembra

```
npm run seed
```

Levantar la aplicación:
```
npm run start:dev
```

Acceder a la aplicación:

`User Service: http://localhost:3001/api/v1`
